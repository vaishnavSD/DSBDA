# Data Science, Business Analytics & Machine Learning

A collection of Jupyter Notebook exercises and assignments covering practical data analysis, machine learning, and data visualization. The repository is organized as individual notebooks rather than a single packaged application.

## Repository Contents

The notebooks currently include work on:

- **Data visualization:** visualization assignments and exploratory plots.
- **Supervised learning:** logistic regression and Naïve Bayes exercises.
- **Data analysis:** coursework and assignment notebooks using Python data tools.
- **Practical assignments:** numbered assignments and topic-specific exercises.

## Technology

- Python 3
- Jupyter Notebook
- Common data-science ecosystem: NumPy, pandas, Matplotlib and scikit-learn (depending on the notebook)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vaishnavSD/DSBDA.git
   cd DSBDA
   ```
2. Create and activate a Python virtual environment (recommended).
3. Install the packages required by the notebook you want to run:
   ```bash
   pip install jupyter numpy pandas matplotlib seaborn scikit-learn
   ```
4. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
5. Open a notebook and run its cells in order. Some exercises expect input datasets to be available locally; update file paths to match your environment.

## Notes

- This repository is a learning and assignment collection, not a deployed application.
- Dataset files may need to be downloaded or placed in the paths referenced inside individual notebooks.
- Notebook names and contents may reflect coursework iterations.
